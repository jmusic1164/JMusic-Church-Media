# JMusic Church Media — Starter Website

A mobile-first static website for church-media tutorials, sermon/Bible outlines, downloads and affiliate recommendations.

## Files
- `index.html` — homepage
- `tutorial-livestream.html` — sample tutorial
- `tutorial-webcam.html` — sample tutorial
- `tutorial-microphone.html` — sample tutorial
- `outline-dying-spirituality.html` — sample teaching outline
- `styles.css` — design
- `script.js` — mobile menu
- `robots.txt` / `sitemap.xml` — SEO basics

## Before publishing
1. Replace `YOUR-EMAIL@example.com` in `index.html`.
2. Replace the `#` affiliate links with your actual affiliate links.
3. Replace download placeholders with your actual PDF/template files.
4. Create Privacy Policy, Terms, and Affiliate Disclosure pages.
5. Replace `YOUR-DOMAIN.com` in `robots.txt` and `sitemap.xml`.
6. Add your Google Analytics/other analytics code if desired.
7. Apply for an ad network only after the site has substantial original content and the required legal/privacy pages.

## Suggested growth plan
Publish 2–3 useful articles each week:
- church livestreaming
- OBS tutorials
- church presentation software
- microphone/audio guides
- webcam/camera tutorials
- sermon/Bible outlines
- church-media checklists

Use TikTok, YouTube and Facebook to send visitors to the relevant tutorial.

## Important
This starter site contains no real ad network account or affiliate account. You must insert your own approved advertising and affiliate codes/links. Do not click your own ads or create misleading clicks.
